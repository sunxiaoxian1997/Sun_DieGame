# Game Vision

## Working concept

A 2D puzzle-platform game in which death is not merely failure. Each death creates a persistent corpse that becomes part of the level.

The player solves a level by deciding:

- where to die;
- how many lives to spend;
- how prior bodies should alter the environment;
- how the current life can exploit those changes.

## Player fantasy

“I construct the solution using my previous lives.”

## First prototype promise

The first playable prototype must prove one idea:

> A player voluntarily dies on a pressure plate, leaves a corpse there, respawns, and walks through the door that the corpse keeps open.

## Target platform

Initial prototype: Windows desktop.

## Camera and presentation

Initial prototype: 2D side view, greybox visuals, fixed or simple follow camera.

## Out of scope for the first prototype

- commercial art quality;
- content volume;
- story;
- special corpse types;
- combat;
- procedural generation;
- final accessibility and platform support.
