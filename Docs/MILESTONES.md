# Milestones

## Milestone 0 — Repository and automation

- project structure;
- assembly definitions;
- command-line validation;
- Edit Mode and Play Mode test assemblies;
- Windows build automation;
- greybox bootstrap scene.

## Milestone 1 — First complete gameplay loop

- player movement and jump;
- normal hazard;
- death;
- limited lives;
- normal corpse;
- respawn;
- pressure plate;
- door;
- exit;
- restart;
- automated tests;
- Windows development build.

## Milestone 2 — Feel validation

Only after Milestone 1 works:

- tune movement;
- tune corpse physics;
- improve death/respawn feedback;
- improve readability;
- conduct external playtest;
- decide whether the core interaction is worth expanding.

## Milestone 3 — Second corpse state

Only after the first loop is accepted:

- choose either fire or ice;
- define complete rules and counter-rules;
- add three greybox levels that introduce, develop, and invert the mechanic.

## Release gate for Milestone 1

Milestone 1 is accepted only when all checks in `README_START_HERE.md` pass.
